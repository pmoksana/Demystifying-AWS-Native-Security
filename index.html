COMPLIANCE TRACKING

Continuous Compliance Monitoring: AWS Config

How It Works
  • Resource Tracking: Records detailed configuration history of every AWS asset.
  • Drift Detection: Flags unauthorized changes violating infrastructure-as-code baselines.
Common Managed Rules
  • Enforce S3 Bucket Private Access (Block public read/write).
  • Ensure MFA enabled on root and privileged IAM accounts.
  • Verify EBS volume encryption at rest across all regions.
THREAT DETECTION

EDR & Continuous Threat Detection: Amazon GuardDuty

Intelligent Analysis

Uses Machine Learning and threat intelligence feeds to analyze native AWS data streams.

Multi-Layer Scope

Monitors CloudTrail events, VPC Flow Logs, DNS logs, S3 access, and IAM activity.

Anomaly Detection

Catches compromised credentials, data exfiltration, and unauthorized API calls in real time.

RUNTIME EDR

GuardDuty Runtime Monitoring

Workload Scope
  • EKS & Kubernetes: Monitors container-level runtime file, process, and network connections.
  • EC2 & Serverless: Lightweight agent tracking operating system behavior.
Capabilities
  • Detects reverse shell execution, privilege escalation, and unauthorized process spawning.
  • Operates as a native lightweight EDR agent without heavy EC2 performance overhead.
OPERATIONAL PIPELINE

The Integrated AWS Security Stack Workflow

1
Stage 1: Proactive Defense (Amazon Inspector)

Continuously scans EC2 instances and ECR images for software CVEs and flags unpatched exposure.

2
Stage 2: Active Threat Detection (Amazon GuardDuty)

Catches an active exploitation attempt, anomalous network connection, or credential theft in real time.

3
Stage 3: Central Response (AWS Security Hub)

Correlates both findings into a single prioritized finding and triggers automated remediation rules.

INCIDENT RESPONSE

Incident Investigation Lifecycle in AWS

1

Alerting: GuardDuty flags unauthorized API call from an unknown foreign IP address.

2

Aggregation: Security Hub ingests alert, applies severity score, and triggers EventBridge rule.

3

Investigation: Engineer opens Amazon Detective to visualize blast radius and impacted IAM roles.

4

Remediation: Automated AWS Lambda function revokes compromised IAM session keys instantly.

ATTACK SCENARIO 1

Real-World Scenario: S3 Bucket Exfiltration

Attack Chain

Malicious actor steals exposed IAM access key from developer repo $\rightarrow$ Scans S3 buckets $\rightarrow$ Begins downloading sensitive customer datasets.

AWS Native Response

GuardDuty detects unusual data access pattern from unrecognized IP $\rightarrow$ Security Hub raises critical alert $\rightarrow$ AWS Config reverts bucket exposure.

ATTACK SCENARIO 2

Real-World Scenario: Container Compromise

Attack Chain

Unpatched web application vulnerability $\rightarrow$ Attacker gains remote code execution on EKS pod $\rightarrow$ Spawns unauthorized crypto-miner binary.

AWS Native Response

Inspector flagged unpatched CVE during build $\rightarrow$ GuardDuty Runtime Monitoring detects unauthorized binary execution inside container pod instantly.
